## نسخهٔ HTML برای خواندن آسان‌تر

در کنار هر فایل مارک‌داون، نسخهٔ HTML همنام (با همان متن، بدون هیچ تغییری) قرار دارد که با قالب کتاب‌گونهٔ پیوست‌شدهٔ کاربر تولید شده است — زمینهٔ کرم گرم، فهرست مطالب تعاملی، سرتیترهای رنگی، جدول‌های سایه‌دار، جعبه‌های نقل‌قول/خلاصه/پانوشت، بلوک‌های شبه‌کد با پس‌زمینهٔ سرمه‌ای، پیوند فصل بعدی/قبلی و شماره‌های پانوشت به‌صورت بالانویس.

- `00-پیشگفتار.html` تا `28-فصل۲۸-آینده-هوش-مصنوعی.html`
- متن HTML با متن مارک‌داون نویسه‌به‌نویسه برابر است (آزمون خودکار روی هر ۳۰ فایل).

## شکل‌های کتاب در فایل‌های HTML

همهٔ **۴۰۷ شکل کتاب** (شکل‌های ۱.۱ تا ۲۶.۳۵ — فصل‌های ۲۷ و ۲۸ و کتاب‌نامه شکل ندارند) مستقیماً از PDF اصلی برش خورده و **دقیقاً در جای کپشنِ همان شکل** در فایل HTML درج شده‌اند. تصاویر به‌صورت base64 داخل خود فایل‌ها جاسازی شده‌اند، پس هر فایل HTML مستقل است و بدون هیچ فایل جانبی، در هر مرورگری (و همین پیش‌نمایش) نمایش داده می‌شود.

- پوشهٔ `figures/ch01/` تا `figures/ch26/` شامل خودِ تصاویر (JPEG باکیفیت، جدا از HTML) است.
- کپشن شکل‌ها زیر هر تصویر با همان متن فارسیِ ترجمه آمده است.
- استثنا: شکل‌های «الگوریتم/شبه‌کد» (مثل DPLL و WALKSAT) که در کتاب به‌صورت کادر کد چاپ شده‌اند نیز به‌همین روش استخراج شده‌اند.
